# Seeders

Coloque aqui arquivos SQL ordenados por nome para dados mínimos ou de demonstração.

Exemplo:

```text
001_roles.sql
002_development_admin.sql
```

Regras:

- não incluir dados pessoais reais;
- não incluir senhas em texto puro;
- separar dados obrigatórios de dados de demonstração;
- executar em produção somente com revisão e `--force`;
- preferir seeders idempotentes quando possível.

O dump histórico `db/inserts.sql` não foi promovido automaticamente porque seu conteúdo ainda precisa ser auditado e classificado.
